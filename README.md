목록의 기준은 [catalog.json](https://raw.githubusercontent.com/skizo-io/dama-materials/main/catalog.json)입니다. 파일 형식은 `dama-card-pack` version 1이며, 각 항목에 바이트 수와 SHA256을 기록합니다.

## 자료와 권리 안내

- 자료의 제목·난이도는 학습 안내이며 공식 시험 지정 목록이나 번역·발음의 전수 검수를 보증하지 않습니다. 일부 카드에는 예문이 없습니다.
- 로마자·가나 읽기는 발음의 근사 안내일 수 있습니다. 단어·뜻·발음·예문은 제공된 자료 기준입니다.
- 출처와 확인 범위는 [SOURCES.md](SOURCES.md), 파일별 재배포 권한 확인 대상은 [RIGHTS_REVIEW.md](RIGHTS_REVIEW.md)를 확인하세요. 공개 다운로드가 가능하다는 사실만으로 모든 자료의 재사용 권한이 확정되는 것은 아닙니다.
- 개인 학습 기록·백업·인증 정보는 공개 자료에 포함하지 않습니다. 앱 프로그램의 라이선스와 자료의 이용 조건은 별개입니다.

## 이미 내려받은 자료와 과거 파일

이미 가져온 카드·꾸러미·학습 기록·복습 일정은 기기에 저장됩니다. 공개 파일이나 목록을 정리해도 기기에 저장된 자료가 자동 삭제되거나 다른 꾸러미로 바뀌지 않습니다.

같은 ID·같은 학습/답안 언어의 자료를 다시 가져올 때 최신 앱은 카드 내용을 갱신하되 기존 학습 기록·복습 일정·꾸러미 소속을 유지합니다. 이전 통합 JLPT를 받은 경우 새 N1~N5 자료가 자동으로 합쳐지거나 이전 꾸러미가 삭제되는 것은 아닙니다. 기존 기록이 있는 자료를 성급히 삭제하지 마세요.

2026-10-20에 현재 목록에 없는 이전 통합 JLPT 4파일과 이전 일영 문법 1파일을 공개 릴리스에서 정리했습니다. **과거 파일의 직접 링크는 더 이상 제공하지 않습니다.** GitHub/CDN 캐시에 따라 옛 링크가 일시적으로 응답할 수 있지만 재다운로드 경로로 의존하지 마세요. 앱의 꾸러미 가져오기를 다시 열어 현재 자료를 선택할 수 있고, 이미 저장한 로컬 파일은 계속 사용할 수 있습니다.

현재 71개 자료의 ID·내용·URL·버전·해시는 이번 안내 정리에서 변경하지 않습니다. 자료를 교체할 때는 `catalog.json`의 version·sha256·bytes·cards·decks를 실제 파일에 맞춰 갱신해야 합니다.
