# Dama study materials

Public catalog for Dama / 담아. Study files are being prepared.

The app downloads only packs selected by the user. One JLPT pack contains N1–N5 as five bundles. No personal study records or credentials belong here.

Catalog: `catalog.json`. Download files are versioned GitHub Release assets in the Dama card-pack format. Materials will be added after content review.
