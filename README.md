## 자료 안내

- CEFR: 대표 뜻 중심이며 예문은 포함하지 않습니다. 일부 번역은 추가 검수가 필요합니다.
- TOPIK: 대역이 확보된 원본 어휘를 부분 수록한 자료입니다. 수준은 추정값이며 공식 TOPIK 등급을 보증하지 않습니다. 발음 표기는 근사치입니다.
- 구조·필수 항목·ID 중복·용량과 앱 가져오기 호환성을 검사했습니다. 모든 번역·용법의 사람 검수를 마친 자료라는 뜻은 아닙니다.
- 같은 자료를 다시 받아도 기존 카드 수정과 학습 기록은 덮어쓰지 않습니다.
- 학습 자료만 공개하며 개인 기록·백업·인증 정보는 포함하지 않습니다.
