## 현재 제공 범위

- 일본어 N1~N5·문법의 일한/일영 12종만 제공합니다.
- 2026-10-12 사용자 요청으로 문제가 있는 기존 CEFR·EIKEN·TOPIK 6종을 목록과 다운로드에서 제거했습니다. 일본어 12종의 내용과 파일은 변경하지 않았습니다.
- 구조·필수 항목·ID 중복·용량과 앱 가져오기 호환성을 검사했습니다. 번역·용법의 사람 전수 검수를 마친 자료라는 뜻은 아닙니다.
- 학습 자료만 공개하며 개인 기록·백업·인증 정보는 포함하지 않습니다.

Catalog: [catalog.json](https://raw.githubusercontent.com/skizo-io/dama-materials/main/catalog.json). Format: `dama-card-pack` version 1.

## 자료 업데이트

파일 교체 시 catalog.json의 해당 항목 version·sha256·bytes·cards·decks도 함께 갱신해야 합니다. 담아에서 가져오기를 다시 열면 최신 목록을 조회합니다.
최신 앱은 같은 ID·같은 학습/답안 언어의 학습 내용을 갱신하며 기존 학습 기록·복습 일정·꾸러미 소속을 유지합니다. 이미 내려받은 자료는 공개 목록에서 제외해도 기기에서 자동 삭제되지 않습니다.
